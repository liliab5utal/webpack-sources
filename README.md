# Anotações soltas

Dá para usar o gerenciador alternativo junto com o runtime. Em aula foi dito que a escolha entre os três mais conhecidos não muda nada de verdade — o professor usa o clássico.

Para adicionar uma dependência usada só em desenvolvimento, basta a flag correspondente:

```sh
npm install -D <nome-do-pacote>
```
